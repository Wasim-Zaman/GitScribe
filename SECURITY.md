# Security Policy

## Supported versions

Only the latest release on the main branch is supported with security updates.

## Reporting a vulnerability

If you discover a security issue in GitScribe (for example, an exposed API key or other sensitive data), please do **not** open a public issue.

Instead, contact the maintainers privately so we can investigate and resolve the issue safely.

We will acknowledge receipt as soon as possible and keep you informed of our progress.
