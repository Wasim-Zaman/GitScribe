## [0.1.0] - 2026-09-12

### Added

- Initial public release.
- CLI that accepts natural-language requests for git commit summaries.
- `fetch_commits` tool to read commits across all branches for a date range.
- `output_rail` tool to generate a TSV report for Google Sheets.
- Commit type classification heuristic (`New Feature` / `Enhancement`).
